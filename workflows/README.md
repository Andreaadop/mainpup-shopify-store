# workflows/

Markdown SOPs (Layer 1 of the WAT framework). Each file describes one repeatable job.

Each workflow should cover:
- **Objective** — what this workflow accomplishes
- **Required inputs** — what the agent needs before starting
- **Tools to use** — which scripts in `../tools/` (in order)
- **Expected outputs** — where results land
- **Edge cases / gotchas** — rate limits, retries, known quirks

Keep these living documents. Update them as you learn.
